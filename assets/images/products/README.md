# Imágenes de productos

Guarda aquí una imagen WebP por producto usando su ID como nombre:

- `OB001.webp`
- `OB002.webp`
- `OB013.webp`
- `OB064.webp`

La versión 0.3.2 incluye las 64 fotografías `OB001.webp` a `OB064.webp` y cuatro
composiciones `KIT01.webp` a `KIT04.webp`, recortadas de las páginas fuente del
catálogo de agosto. No se utilizaron fotografías genéricas ni referencias
diferentes.

Recomendación: lienzo cuadrado de 600 x 600 px, fondo blanco o transparente y
peso máximo aproximado de 150 KB. Si en una actualización futura falta una
imagen, la aplicación mostrará automáticamente el ícono de respaldo.
